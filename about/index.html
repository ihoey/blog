小栈历程

  1. 2026-10-02

    从 Hexo 走向 Astro

    小栈换上 Astro，继续沿用熟悉的 NexT 气质。旧文章、链接和历史评论都留了下来，伊布、小猫和打赏也一起搬了新家；加入日夜切换、霞鹜文楷、Dracula 代码高亮，重新整理导航、目录、归档和标签云，并优化图片与图标加载。

  2. 2026-09-18

    评论升级，小猫回到小栈

    接入 Hitalk v3，恢复文章评论数，补上评论互动、颜文字和点击呼唤的页脚小猫。

  3. 2025-03-17

    整理站点验证与统计

    补上百度站点验证配置，停用旧腾讯分析，让小栈继续轻装运行。

  4. 2023-08-31

    更新友链与依赖管理

    这一年继续整理友链，并用 pnpm 锁文件替换 Yarn 锁文件，维护博客的构建环境。

  5. 2022-09-17

    继续写些有趣的东西

    更新《羊了个羊》程序员过关攻略，记录用 Rust 折腾小游戏的过程。

  6. 2021-11-26

    整理小栈的朋友们

    重新整理友情链接，清理无法访问或已无本站链接的站点。

  7. 2021-01

    整理静态资源与发布流程

    将静态资源迁至 cdn.ihoey.com，并调整部署脚本，继续维护小栈的访问与发布。

  8. 2020-07-23

    升级 Hexo 4.2.1

    从 Hexo 3.7.1 升级到 4.2.1，同步更新文章生成、RSS、站点地图和部署相关依赖。

  9. 2019-02-12

    尝试 PWA 与离线阅读

    加入应用清单与 Service Worker，探索添加到主屏幕和离线访问。2026 年迁移时暂缓离线功能，并清理旧缓存。

  10. 2018-04-28

    升级 NexT 6.2.0

    更新 NexT 主题，继续沿用 Muse 布局，在熟悉的样子上慢慢折腾。

  11. 2018-04-21

    接入 Hitalk 评论

    启用 Hitalk 评论，继续为文章和留言保留一个交流的地方。

  12. 2018-03

    打赏与代码块有了自己的样子

    加入定制打赏组件，并单独设计代码块样式，让阅读和互动都多一点小栈的个性。

  13. 2017-12-24

    换上 Wildfire 评论

    从萌评切换到 Wildfire，继续折腾博客的评论体验。

  14. 2017-08-13

    尝试萌评

    接入萌评，为文章和留言页更换评论入口。

  15. 2017-06-05

    从多说换到网易云跟帖

    多说停止服务后，紧急切换到网易云跟帖；旧评论的数据导入并不顺利。

  16. 2017-04-21

    加入自动构建

    接入 Travis CI，让博客的构建和发布开始自动化。

  17. 2016-12-06

    伊布住进小栈

    在页脚加入用 HTML 和 CSS 实现的伊布。从那时起，它就陪着大家一起看文章。

  18. 2016-10-25

    从 SAE 迁往 Coding / GitHub

    站点从SinaAppEngine(SAE)迁移到Coding/GitHub, 国内用户默认解析至Coding, 海外则解析至GitHub, 互为备份, 改善了访问速度与稳定性
