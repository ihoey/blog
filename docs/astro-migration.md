## 已核实的现状

- Hexo 声明与原目录安装版本均为 `4.2.1`；当前主题为 `themes/next`，NexT `6.2.0`，使用 Muse 布局；另有 `next5` 旧主题。
- `source/_posts` 有 57 篇 Markdown，线上导航同样显示 57 篇。发布日期范围为 2015-08-28 至 2022-09-17。
- 所有文章都有 `title`、`date`、`tags`、`categories` 字段。原时区为 `Asia/Shanghai`，日期写法可能不补零，转换时不能依赖模糊的运行环境日期解析。
- 附加页面包括 about、links、guestbook、tags、categories；另外需要归档、分页、RSS 和 sitemap。
- 文章链接规则为 `posts/:category/:year-:month-:day-:title.html`，分类可以有多级且包含大小写。线上示例：`/posts/javascript/PWA/2019-02-18-progressive-web-apps-blog.html`。
- 当前评论使用 Hitalk SDK `3.0.0`，API 为 `https://hitalk-next-api.ihoey.com/api`，接入说明见 `docs/hitalk.md`。
- Hitalk 页面标识取页面路径，去除域名、查询参数和片段，并将末尾 `/index.html` 归一化为 `/`。文章路径和留言板标识需要保持一致。
- 主题里有自定义代码块、伊布、友链样式、页脚小猫与评论动画。具体保留方式在实现前清点，不将整套旧主题脚本直接搬入新站。

- `scripts/events.js` 的 `deployAfter` 会执行旧服务器 SCP 上传及自动 Git 提交、拉取、推送。现有 `start` / `deploy` 均涉及发布，不适合预览。
- 按已有 `docs/hitalk.md` 记录，生产使用 Vercel 监听 `master` 静态分支；本轮未重新查询托管平台设置。
- 搜索发现的 `{% ... %}` 主要位于教程代码块中，已抽查 `Hexo-NexT-Wildfire.md`。不能据此判定文章依赖模板渲染或进行全局替换。
- 存在外部 CDN 图片、原始 HTML 与 iframe 示例，需要逐项区分真实嵌入和文章中的代码示例。本轮未全面检查外链可用性。

## 已确定的迁移原则

1. 使用 Astro，以静态内容网站为主；已有 Markdown 优先原样复用，需要交互时再引入组件。
2. 保留站名、正文、发布日期、分类层级、标签以及旧文章地址。旧链接应优先直接返回原文章；确有地址变更时才安排明确重定向。
3. 保留 Hitalk 服务和历史评论关联，移植前端接入与必要样式，不迁移评论数据库。
4. 初期用代表性文章建立预览和兼容性验证，再导入全部 57 篇。
5. 原站继续可用；本地构建和测试不能触发生产发布、评论写入或邮件发送。
6. 不先决定更换托管平台。新的发布方式、旧 Service Worker 处理与回退方案在上线前落实。
