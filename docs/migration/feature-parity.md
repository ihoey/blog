## 验证结果

- `pnpm build`：183 个博客 HTML 页面（比上一轮增加 `/400.html`；另有独立站长验证文件）。
- `pnpm verify`：57 篇文章、182 个原基线地址、576 个旧锚点，无内部断链；新增功能产物检查已纳入同一命令。
- `pnpm test`：22 项通过；`pnpm check`：44 文件，0 错误 / 警告 / 提示。
- RSS 使用 XML 解析器验证有效，20 个条目均含全文，与旧 Atom 的 entry ID 顺序逐一一致；Baidu sitemap 可解析且含 57 篇文章。
- 真实浏览器：PWA 五张图片放大、下一张、Esc 关闭、焦点返回通过；图片均加载成功且为 lazy。WebRTC 长正文真实复制后包含作者 / 正式 URL，复制代码无附注。随机一言成功显示，正文 H1–H6 目录对应原节点。
- 本地独立 origin 使用原 `source/sw.js` 原样注册：旧 Worker 控制客户端、旧首页确实命中缓存；切换新版 Worker 后自动刷新，首页成为新版本，注册数为 0，旧 bs/api 缓存消失，特意保留的 unrelated 测试缓存仍在。退役操作仅一次，下一页没有再次注册代码。
- 补 `static/vercel.json`，静态发布时保证 `/sw.js` 使用 no-cache / no-store 与正确 JavaScript 类型；上线后已确认正式响应头正确。
- 未逐页人工操作所有 57 篇文章，也未发送真实评论、通知、支付或搜索引擎提交；未重新验证所有外部友链可用性。旧失效演示与徽章继续使用已有降级处理。
