# 梦魇小栈 · 第二版视觉建议

日期：2026-09-22。本文保留迁移早期的建议和当时观察，包含后来已被替代的方案。当前网站已经上线；最终配色、布局、导航和交互以根 PRODUCT.md 为准，当前实现与验证见 docs/astro-migration.md。

## 核心判断

首版完成了内容迁移，却把「清爽阅读」解释得过于简化。用户喜欢的是带有个人痕迹的博客：封面、站牌、宠物、作者信息以及不断发现的小互动。第二版应恢复这些特征，再改善排版与动效细节。

推荐方向：「NexT 的小栈，长出新的细节」。以原站为主，借鉴 Josh 的场景层次和余弦的信息组织，不直接套用另一套主题。

## 推荐页面结构

### 首页

1. 顶部为约 320–380px 的封面区域。首先沿用自己的彩色树叶视觉，重新调整裁切、色彩密度与底部过渡；站牌「梦魇小栈」、副标题「专注于分享」与图标导航仍居中。具体尺寸在实际预览时调节，目标是在常见桌面首屏看到第一篇标题。
2. 正文区约 1060px 宽，左侧约 220px 的作者区域，右侧为约 720px 的文章列表。作者区放原头像、原签名、57 篇文章 / 18 分类 / 49 标签、真实社交入口；不编造作者近况或热门榜。
3. 文章标题保留 NexT 的居中气质，元信息在下面；摘要左对齐，分隔线恢复剪刀彩蛋。首页避免展开整块长代码；技术文章可直接用文字摘要，不依赖统一封面图。
4. 伊布恢复陪伴位置并保留气泡反馈；桌面上位于不遮挡正文的边缘，手机上安排在作者区或页脚。
5. 页脚恢复运行时间、原小猫互动与站点信息。把首版通用式自我介绍大标题让位给博客自己的站牌。

### 文章页

- 使用较矮的站头，尽快看到标题与正文。
- 阅读栏约 720px，桌面配粘性目录与阅读进度；移动端目录折叠。
- 保留淡玫红行内代码、自己的代码块风格、清楚的代码语言和复制反馈；长代码横向滚动。
- 引用、提示、图注、表格有明确层级，整体仍沿用安静的阅读底色。
- 文末接上下篇与 Hitalk，保留已有 URL、评论标识、原始 Markdown。

### 色彩与字形

- 日间：偏暖的白色阅读底、浅灰环境色，原站玫红作为互动强调色；丰富色彩集中于封面。
- 夜间：深蓝灰背景与暖白正文，封面单独调整亮度，代码主题一并匹配。
- 中文正文用现有中文系统字体；站名可以保留原站字形气质。避免大面积渐变字或把全站做成卡片墙。

## 旧效果清点与升级建议

以下源于旧 `custom.styl` 和 `set.js`，不代表首版已经保留，也不代表本轮逐个在浏览器验收过。

| 旧效果 | 第二版建议 |
| --- | --- |
| 伊布与欢迎/悬停气泡 | 重点恢复；气泡按操作出现并自动退场，保留原文案中的个性 |
| 页脚小猫 | 保留现有资源与点击互动 |
| 剪刀划过虚线 | 恢复，作为文章间有辨识度的小彩蛋 |
| 头像旋转 | 保留为悬停/点击触发，调整为轻快、短暂的动作 |
| 点击爱心与特殊光标 | 纳入「个性效果」开关；爱心避免在输入、文本选择时触发 |
| 一言 | 首页固定位置展示，读取失败保留本地文案，避免页面跳动 |
| 标题/阅读全文悬停位移 | 改为 transform 与下划线反馈，不推动旁边文字布局 |
| 切走页面时标题变化 | 可保留温和的招呼文案，避免旧“页面崩溃”提示造成误解 |
| 复制时附加版权 | 提供单独的转载信息入口；代码复制保持可直接使用 |
| 运行时间、回顶、滚动百分比 | 恢复并融入侧边工具区 |
| 打赏弹层和友链样式 | 沿用现有内容与资产，第二批匹配新视觉 |

新增动效以导航反馈、主题切换和适量入场为主。尊重 reduced-motion，提供安静模式；这不是删掉个性，而是让访客可自行控制陪伴强度。

## 实施顺序与验收

1. 保留现有首版提交作为对照，在当前隔离 worktree 继续；制作第二版首页和一篇长文章的视觉预览，先确定结构、封面、侧栏和阅读节奏。
2. 恢复旧个性效果，完善夜间模式和手机布局，再覆盖归档、友链、留言等页面。
3. 检查每个效果的键盘/触屏行为、弹层关闭、正文遮挡和减少动画偏好；之后运行现有内容、URL、锚点、评论身份与构建校验。
4. 视觉验收后再进入上线阶段；当前没有推送或发布。
