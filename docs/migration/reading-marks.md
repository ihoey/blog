# 正文标记

正文 `.prose` 与首页摘要 `.post-excerpt` 共用这些样式，无需修改已有 Markdown。

| 用途 | 写法 | 效果 |
| --- | --- | --- |
| 日常重点 | `**重要概念**` | 加粗与下半部杏橙 SVG 笔刷 |
| 轻声补充 | `*补充说明*` | 斜体与柔和玫红 |
| 下划线 | `<u>划个重点</u>` | 莓红 SVG 波浪线 |
| 特别高亮 | `<mark>重要的一句话</mark>` | 淡金 SVG 荧光笔 |
| 删除内容 | `~~旧说法~~` | 灰色轻斜 SVG 删除线，文字保持可读 |

`__文字__` 在 Markdown 中仍是加粗，不是下划线。`==文字==` 未添加解析扩展，请使用 `<mark>`。

- 笔刷和线条以行内背景绘制，`box-decoration-break: clone` 让跨行各自保留笔触。没有绝对定位遮罩，不改变正文宽度，不拦截选字与复制。
- 悬停加粗 / 高亮时，在始终可见的基础笔触上用 350ms 补一笔；波浪线以 350ms 滑过一个波长。均不循环，无入场动画、额外脚本或动画依赖。
- 日夜使用独立 SVG 色值。系统减少动态时保留静态样式；打印 / 强制颜色模式恢复普通下划线、删除线和强调。
- 嵌套强调只保留外层主要笔触，保留字重与斜体；嵌套删除语义仍显示删除线。链接、标题、图标和代码不叠笔刷，保留自己的视觉识别。
- 原始文章内容不自动新增高亮。建议仅在真正需要特别提醒的句子上使用 `<mark>`。

实现：`src/styles/reading-marks.css`，从 `Base.astro` 在现有样式之后导入；SVG 在 `static/design/marks/`。

## 引用

沿用 Markdown 的 `> 引用内容`，所有正文区域（文章、关于、留言、其他独立页及摘要）统一显示为暖杏底色、左上角橙色 SVG 引号与独立留白，不加竖线或阴影。正文保持原字号和清晰文字色，不强制整段斜体。

长引用自然换行，内部列表、图片和代码继续使用原样式；嵌套引用去掉内层底色、缩小引号并缩进。可选的 `<cite>` 或 `<footer>` 来源信息显示为较小字号，不自动虚构出处。需要居中寄语时使用 `<blockquote class="blockquote-center">寄语</blockquote>`，会显示为无底色签笺、玫红引号与金色收笔线；两种引用都不绑定页面。

日夜独立调色，窄窗口收小内边距；没有持续动画。打印和强制颜色模式改用常规竖线区分引用。

## 正文标题 H1–H6

沿用 Markdown 的 `#` 到 `######`，不更改现有标题文字、标签级别或锚点。样式仅作用于文章正文，页面主标题、关于页、导航、摘要标题保持独立设计。

| 级别 | 字号 | 视觉 |
| --- | --- | --- |
| H1 | 28–32px | 大章节，粗体与充分留白 |
| H2 | 24–27px | 葡萄紫章节标题，左侧细书签 |
| H3 | 21–23px | 小节，左侧紫色开放括角 |
| H4 | 20px | 普通粗体，收紧段落间距 |
| H5 | 18px | 正文色粗体，细节标题 |
| H6 | 16px | 灰色粗体与轻微字距，不小于正文字号 |

长标题自然换行，不截断；连续标题缩小上间距。H2 / H3 使用独立紫色标记，与正文笔刷区分；无自动编号，标记不写入原文或目录。没有标题入场 / 悬停动画，目录仍使用原来的 ID。打印 / 强制颜色保留层级，去掉装饰。实现位于 `src/styles/article-headings.css`。
